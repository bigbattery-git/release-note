# 001. 개발 환경 구축

- 작성일: 2026-09-06
- 기준: 프로젝트 시작 시 전달된 최초 Task Spec
- 관련 작업 기록: [001. 개발 환경 구축과 Fast Refresh 문제 해결](../work_logs/001_개발환경_구축.md)

## 1. 목표

Node.js 기반 스케줄링 서버를 개발할 수 있는 최소 실행 환경을 준비한다.
Docker Compose로 Node.js 스케줄러, Next.js, MariaDB를 함께 실행한다.

## 2. 배경

- 프로젝트가 구성되지 않은 초기 상태이다.
- 로컬에서 Node.js나 MariaDB를 별도로 실행하지 않고 Docker Compose를 기준으로 개발 환경을 시작해야 한다.
- 실제 서비스 기능은 구현하지 않고 향후 개발에 필요한 최소 환경만 구성한다.

## 3. 요구사항

### Node.js 스케줄링 서버

- Node.js 서버를 구성한다.
- 스케줄링 방식으로 매초 다음 문자열을 로그에 출력한다.

```text
수신중
```

- `setTimeout` 반복 호출, `setInterval`, 직접 작성한 Timer 반복 루프는 사용하지 않는다.

### 스케줄링 방식 선정

외부 라이브러리가 필요하다면 구현 전에 사용 가능한 방법 또는 라이브러리 2~3개를 제시한다.
각 선택지에 대해 다음 항목을 비교한다.

- 동작 방식
- 장점
- 단점
- 현재 프로젝트에 적합한 정도

비교 후 가장 적절한 방법을 추천하고 이유를 설명한다.
최종 구현에는 선택한 스케줄링 방식 하나만 사용한다.

### Next.js

- 애플리케이션이 실행 가능한 최소 환경을 구성한다.
- Docker Compose 실행 후 별도의 `npm run dev` 명령 없이 브라우저에서 페이지에 접근할 수 있어야 한다.
- 별도의 UI나 기능은 구현하지 않는다.

### MariaDB

- MariaDB 컨테이너를 Docker Compose에 포함한다.
- 정상적으로 실행 가능한 상태까지만 구성한다.
- 테이블, 애플리케이션 DB 스키마, ORM, 마이그레이션은 구현하지 않는다.

### Docker Compose

다음 세 서비스를 구성한다.

| 서비스 | 역할 |
| --- | --- |
| Node.js scheduling server | 매초 로그를 출력하는 스케줄러 |
| Next.js | 브라우저에서 접근 가능한 최소 애플리케이션 |
| MariaDB | 정상 실행 가능한 데이터베이스 컨테이너 |

아래 명령만으로 필요한 서비스가 실행되어야 한다.

```sh
docker compose up --build
```

## 4. 제약사항

- 스케줄링 구현에 필요한 라이브러리 외에 불필요한 외부 라이브러리를 추가하지 않는다.
- Node.js와 Next.js 애플리케이션 실행에 필수적인 패키지는 허용한다.
- ORM을 설치하지 않고 데이터베이스 테이블이나 애플리케이션 스키마를 생성하지 않는다.
- 실제 비즈니스 기능을 구현하지 않는다.
- 현재 단계에 필요하지 않은 폴더나 파일을 미리 생성하지 않는다.
- 향후 기능을 예상한 과도한 추상화나 구조를 만들지 않는다.
- Node.js 스케줄링에는 직접적인 Timer 반복 호출 방식을 사용하지 않는다.

## 5. 완료 조건

다음 조건을 모두 만족해야 한다. 이 표는 요구사항이며 실제 검증 결과는 작업 로그에 기록한다.

| 번호 | 조건 |
| --- | --- |
| 1 | `docker compose up --build`로 Node.js, Next.js, MariaDB가 실행된다. |
| 2 | 별도의 `npm run dev` 실행 없이 Next.js 페이지에 접근할 수 있다. |
| 3 | Node.js 컨테이너 로그에 매초 `수신중`이 출력된다. |
| 4 | `setTimeout`, `setInterval` 기반 반복 실행이나 직접 작성한 Timer 루프를 사용하지 않는다. |
| 5 | MariaDB 컨테이너가 정상 실행 상태를 유지한다. |
| 6 | 불필요한 외부 라이브러리가 설치되어 있지 않다. |
| 7 | 이번 작업 범위를 넘어서는 기능이 구현되어 있지 않다. |

## 6. 작업 범위에서 제외하는 항목

- 실제 서비스 및 API 기능 구현
- DB 테이블 설계와 애플리케이션 DB 스키마 생성
- ORM 도입과 마이그레이션
- 인증·인가
- 데이터 저장 및 조회
- 향후 기능을 위한 폴더 선생성
- 테스트 코드 구축
- 배포 환경 구성
- CI/CD 구성

## 7. 후속 요청과의 구분

이 문서는 최초 요청을 정리한 명세이다. 이후 추가 요청된 TypeScript 전환,
Tailwind CSS, 핫리로드 및 문서화는 최초 요구사항에 소급하여 포함하지 않는다.
실제 추가 작업과 문제 해결 과정은 관련 작업 로그에서 확인한다.
